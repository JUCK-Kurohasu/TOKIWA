# ADR-0006: 生成AI攻撃の検知アプローチと能動的防御の線引き

- 状態: 採用（2026-10-22）
- 決定:
  1. AI エージェント攻撃は「アクターセッション」単位の振る舞い特徴量（タイミングのリズム、応答条件付き変異、
     意味的探索、自然言語痕跡、ツール指紋）で説明可能なスコアにする。ブラックボックス ML は使わない（要件の対象外
     「独自 ML モデルの学習」に従う）。重みは評価セットで調整。
  2. 決定的証拠として Mirage の AI カナリア（隠し指示への追従）を使う。
  3. 能動的防御は自組織資産上のデセプション・tarpit・可逆な遮断に限定。反撃は行わない。
- 不確実性: 特徴量は仮説であり、LLM の高速化・攻撃者の回避（ランダム遅延・UA 偽装）で劣化しうる。
  評価ハーネスで継続的に検証し、docs/detection/ai-attacks.md に限界を明記する。
