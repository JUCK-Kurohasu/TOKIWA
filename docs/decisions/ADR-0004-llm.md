# ADR-0004: LLM — ゲートウェイ集中・ティア分け・構造化出力・ルール主/LLM 補助

- 状態: 採用（2026-10-22）
- 決定:
  1. すべての LLM 呼び出しは `LLMGateway` 経由（予算・入力上限・監査・モデル選択・スキーマ検証）。
  2. プロバイダ: Anthropic（主）、OpenAI 互換（ローカル LLM・データを外に出せない環境）、Mock（テスト・キー無し）。
  3. ティア: fast = `claude-haiku-5-5`（一次トリアージ）、deep = `claude-opus-5-5`（昇格・助言・リサーチ）。
     ユーザー要件「軽量モデルで一次、必要時のみ上位モデル」に基づく。設定で変更可。
  4. 出力は Pydantic スキーマ固定（`messages.parse`）。evidence_ids 実在検証。
  5. 拒否（refusal）・予算超過・不正出力はルールベース判定へフォールバック（検知は止めない）。
  6. Web リサーチはサーバーサイド web_search ツール（信頼ドメインの許可リスト）。
- リスク: セキュリティ内容が安全分類器（cyber）に当たる → フォールバック + server-side fallback を有効化。
  モデル ID・価格は変わるので `llm/pricing.py` と設定で上書き可能にし、定期確認（TODO(verify)）。
