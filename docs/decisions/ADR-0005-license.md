# ADR-0005: ライセンス — Apache-2.0（暫定）

- 状態: 暫定採用（2026-10-22）。**公開前にユーザーが最終判断**（要件 未決 #7）。
- 決定: Apache-2.0。特許条項があり、セキュリティツールの企業利用で受け入れられやすい。
- 注意: ARTEX は AGPL-3.0。TOKIWA は ARTEX のコードを一切複製していない（設計思想・UI の方向性のみ参考）。
  ARTEX のエクスポート形式を読むアダプタはファイル形式の相互運用であり、コード流用ではない。
- 代替: MIT（より単純）。依存ライブラリは MIT/BSD/Apache 系のみで、どちらでも互換。
