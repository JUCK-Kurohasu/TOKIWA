# Web UI 指南

TOKIWA 的界面通过 `http://<服务器>:8788` 打开。左侧边栏分为 5 个分组。
可以通过右上角的按钮切换 **显示语言（日本語 / English）** 和 **浅色 / 深色主题**。
告警和安全事件会实时更新（SSE）。

日期时间总是附带时区名称（例如 `2026/11/11 9:43:09 JST`）。右上角的时钟按钮（显示 `JST`、`UTC` 等）可切换
**显示时区（浏览器本地 / UTC）**，选择按浏览器记住。将鼠标悬停在时间上，还会显示 UTC 的 ISO 8601 格式
（例如 `2026-11-11T00:43:09.000Z`）。API、原始数据（JSON）、Gate 和日志中的时间始终为 UTC。
Events（事件）页面的自定义时间范围也按显示时区解释输入的时间。

Web UI 只提供日语和英语界面。本页用加粗的英文界面标签指代各项，并在首次出现时用括号附上中文译名。

## 角色（权限）

| 角色 | 可执行的操作 |
|---|---|
| `viewer` | 仅查看。事件中的请求体、查询字符串、请求头的值、命令行和提示词以掩码（`[redacted: analyst role required]`）显示。默认不能使用 Copilot（`copilot.min_role`） |
| `analyst` | 在查看之外，还可执行分诊（研判）、更新安全事件、**批准、拒绝、撤销处置**、编辑欺骗防御资产等 |
| `admin` | 全部操作。管理用户、API 令牌、通知渠道、LLM 设置 |

最初在初始设置页面创建的用户是 `admin`。添加用户请在 **Settings → Users**（设置 → 用户）中进行。

登录的有效期默认为 12 小时（`server.token_ttl_minutes`）。右上角的 **Log out**（退出登录）会使该用户在 **所有终端** 上的登录失效。修改用户的密码或角色时，该用户已有的登录也会失效，需要重新登录。管理员可以在 **Settings → Users** 中通过 **Revoke sessions**（使会话失效）让其他用户在所有终端上退出登录（例如怀疑登录信息被盗时）。

## Monitor（监控）

### Dashboard（仪表盘）

过去 24 小时的整体概况。来源于 AI 智能体的信号以 **紫色** 显示。

- 上方的卡片：**Alerts (24h)**（告警数，按严重级别）、**Open incidents**（未关闭的安全事件）、
  **AI agent sessions (24h)**（AI 智能体会话数）、**LLM cost (today)**（今日 LLM 费用与预算）、
  **Pending actions**（待批准的处置）、**KEV matches**（已知被利用漏洞（KEV）与资产的匹配数）
- 活动：事件与告警的趋势（6 小时～7 天）
- 实时动态：打开页面之后新到达的告警、安全事件、处置提议
- 排名靠前的来源、排名靠前的规则、最近的安全事件

### Alerts（告警）

各个检测结果的列表。可以按状态、严重级别、类别、来源 IP、AI 评分筛选。
在详情页面中，可以查看作为依据的事件（证据）和 LLM 的分诊结果，并可以手动重新执行分诊。
告警详情中的 **Token / sensor that delivered the evidence（发送证据的令牌 / 传感器）** 会列出发送证据事件（最新 200 条）的令牌和传感器（与下文“处置”中的显示相同）。

将状态设为 **False positive（误报）** 时，会打开一个对话框，用于选择再次发生时的处理方式（列表的批量更改也相同）。

| 选项 | 行为 |
|---|---|
| 服务器默认（初始选择） | 在 `detection.fp_suppress_hours`（默认 168 小时）内，相同的检测（相同规则、匹配的签名、路径、来源）再次发生时不新建告警，而是计入此告警的次数。不会触发分诊、通知或关联到事件 |
| 不抑制 | 再次发生时照常新建告警 |
| 抑制指定小时数 / 永久抑制 | 更改期限（永久即直到解除） |
| 不论来源一律抑制 | 针对同一路由和参数的同类检测，无论来自哪个来源都会被静默。攻击者以相同形式攻击也会被漏掉，因此仅限于来源众多且每次不同的正常输入 |

新的签名、不同的参数或严重级别上升不会被抑制。被标记为误报的告警详情中会显示由该告警创建的抑制（期限、抑制的次数）和 **Lift（解除）** 按钮。
将状态从误报改回其他状态时，抑制也会被解除（会先确认）。

### Suppressions（抑制与允许列表）

被标记为误报的告警的再发抑制，以及已授权的漏洞扫描和压力测试的 **允许列表（allowlist）** 的一览（可按类型筛选，可切换显示已过期 / 已解除的项）。
抑制期间的检测不会产生新告警、分诊、通知或处置建议。**Lift（解除）** 需要 `analyst` 及以上权限。

**Create allowlist（创建允许列表）** 仅限 `admin`。来源 CIDR 和期限（小时）为必填，规则 ID 和路径为可选。

- 期限上限为 `detection.allowlist_max_hours`（默认 720 小时）。不能创建永久的允许列表。
- 不能创建比 IPv4 /8 或 IPv6 /32 更宽的范围。
- 处理方式为 "Record as info"（默认：仍留在告警列表中，但不分诊、不通知、不建议）或 "Don't record"（仅计数）。
- 不限定规则的允许列表也会静默欺骗防御（触碰诱饵）和 AI 智能体判定的告警。请将范围和期限保持在最小。

### AI sessions（AI 会话）

按 **来源 + 客户端指纹** 汇总的行为单位（会话）。根据行为特征推定为
“AI 智能体 / 自动扫描器 / 人类 / 正常”，并给出 AI 评分。

- 列表：AI 评分、分类、请求数、错误率、路径数、持续时间
- 详情：请求时间线。与上一个请求的间隔（ms）会按“突发 / 中间 / 等待思考 / 长”的区间
  着色，可以看出 AI 智能体特有的 **突发 → 停顿 → 突发** 节奏。还会显示评分明细（哪些特征起了作用）。

### Hosts（主机）

TOKIWA Agent 发送过来的主机信息。标签页：**Ports**（端口：监听列表）和 **Baselines**（基线：许可列表）。
不在基线中的监听会被检测为“偏离”。

## Investigate（调查）

### Copilot（AI 助手）

可以用自然语言就 TOKIWA 的数据提问的聊天功能（例如：“今天被判定为 AI 智能体的来源有哪些？”）。
**Copilot** 可使用的工具是 **只读** 的，无法修改设置或执行处置。未设置 LLM 时，
返回的是模拟应答。

考虑到 LLM 可能会听从攻击者埋在遥测数据中的指令，回答中的链接按以下方式处理：

- TOKIWA 内部链接只有指向已知页面（告警、事件（Incident）、会话、事件（Event）等）时才会在同一标签页中打开。
- 外部链接只有指向允许站点（NVD、MITRE、CISA、JVN、OSV、FIRST）的 https 页面时才可点击，并在显示名称旁显示实际主机名。
  其他链接显示为不可点击的文本，并附上主机名和“链接已禁用”（link disabled）。
- 显示名称是 URL 形式但与实际链接目标不同时，会显示“显示名称与链接目标不一致”（label and destination differ）警告。

允许的站点可在 `frontend/src/components/common/linkPolicy.ts` 的 `EXTERNAL_LINK_ALLOWLIST` 中修改（需要重新构建）。

### Incidents（安全事件）

将相关告警按来源、会话、实体归并而成。

- 列表：严重级别、状态、**Actor attribution**（行为者判定：AI 智能体 / 人类 / 扫描器等）、AI 评分
  （行为者判定由规则和行为特征决定。仅当规则无法判定时才使用 LLM 的判定，并且只用于提升为 AI 智能体 / 扫描器；
  LLM 判定为“人类”或“无害”时不会改变）
- 详情：攻击阶段（杀伤链：侦察 → 初始入侵 → …）、LLM 的分诊（摘要、依据、推荐处置）、
  LLM 列出的“AI 参与的依据”、相关告警。可以分配 **Assignee**（负责人）并更新 **Status**（状态）。

对于 LLM 分诊中包含的依据（证据 ID），服务器会验证其是否对应真实存在的事件。

### Events（事件）

检索已摄取的原始事件。可以按类型、数据集、来源 IP、主机、时间范围、关键字（路径 / User-Agent）筛选。

当路径、User-Agent、请求头、请求体等包含 **不可见字符或会改变显示顺序的字符**（双向控制字符 U+202E、零宽字符 U+200B 等）时，
这些字符会以警告色显示为 `⟨U+202E⟩` 的形式，并在该行或事件上加上“包含不可见/双向控制字符”（Contains invisible / bidi control characters）标记
（用于防范把 `invoice⟨U+202E⟩fdp.exe` 伪装成 `invoiceexe.pdf` 的手法）。原始数据（JSON）中显示为 `\u202E`。
替换仅作用于显示，搜索和筛选仍使用原始字符串。适用于事件列表、事件详情、告警证据、会话详情以及 Copilot 的回答和工具结果。

## Intelligence（情报）

### Intelligence

漏洞信息以及与资产的比对结果。标签页：**Vulnerabilities**（漏洞：整合 KEV / EPSS / NVD / JVN / OSV / GHSA）、
**Asset matches**（资产匹配）、**Advisories**（安全通告：由 LLM 给出的带优先级的建议）、**News**（新闻：RSS）、**Web research**
（Web 调研：由 LLM 进行的 0day 调查）、**Sources**（数据源状态）。详情请参阅 [漏洞情报](Threat-Intel-zh)。

GHSA / OSV 撤回（因误报、重复等原因收回）的通告，会在漏洞列表、详情和资产匹配中以 **Withdrawn（已撤回）** 徽章标示
（整个漏洞已被撤回，基于它的暴露已自动关闭）。若仅部分通告被撤回、NVD 等其他来源的数据仍然保留，则显示 **Partly withdrawn（部分撤回）**。
将鼠标悬停在徽章上可查看被撤回的通告 ID 和日期。徽章表示漏洞的状态，并不断定某个暴露被关闭的原因（自动关闭的原因栏仍为原有文字）。

### Assets（资产）

登记需要保护的主机，以及在其上运行的软件（产品名、版本、CPE）。登记的资产会用于与漏洞信息的
比对，以及安全事件的优先级排序（是否命中 KEV）。

### Rules（检测规则）

- **Detectors**（检测器）：启用 / 禁用内置检测器（Web 攻击特征签名、AI 行为、欺骗防御、端口等）
- **Sigma rules**（Sigma 规则）：管理 Sigma 格式的规则（内置 25 条 + 追加的规则）。内置的 14 条 Web 攻击规则，如果同一请求中
  同类的内置 Web 检测器也告警，就合并到该检测器（只产生 1 条告警，记录在 `details.corroborated_by` 中）；如果检测器已启用却没有
  告警，则以 low 记录。只有在禁用该检测器时，规则才以自身的严重级别告警
- **LLM proposals**（LLM 提议）：LLM 根据漏洞信息提议的规则。**不会自动启用**，需经审查后再采用

## Respond（处置）

### Response（处置）

由 LLM、规则、用户提议的处置列表。标签页：**Awaiting approval**（待批准）/ **Active**（生效中）/ **History**（历史）/ **Suppressions**（抑制：拒绝或撤销时标记为“不再提议”的目标，可在此解除）。
批准、拒绝、撤销需要 `analyst` 及以上角色。详情请参阅 [处置（审批流程）](Response-zh)。

批准对话框中会显示作为处置依据的告警（仅关联到事件的处置则取该事件中最多 5 条告警）的证据 **由哪个 API 令牌、哪个传感器发送**
（来自事件的 `ingest.token` / `ingest.token_id` 标签）。因令牌绑定而被替换的 sensor_id（`ingest.claimed_sensor_id`）也会显示。
若证据中包含 **来自没有 gate 范围的令牌的 Gate / 欺骗防御遥测**（`ingest.trust=low`），会显示可能被伪造的警告：令牌被盗时可以伪造来源 IP 和触碰诱饵的记录，
因此批准前请通过 Gate 日志或其他传感器确认来源。没有来源标签的事件（标签引入之前的数据，或 TOKIWA 内部生成的事件）显示为 "No provenance record（无来源记录）"。

### Deception（欺骗防御）

管理诱饵、honeytoken、AI 金丝雀、迷宫，以及查看触碰它们的记录（trip）。
也可以预览下发的内容。详情请参阅 [欺骗防御（Mirage）](Deception-zh)。

## System（系统）

### LLM

- **Settings**（设置）：提供商、模型（轻量 / 高级；Anthropic 下为下拉选择）、每日预算、输出语言、API 密钥（只写）。带有 **Connection test**（连接测试）按钮
- **Usage**（用量）：按日统计的费用、调用次数、token 数（按用途）
- **Call log**（调用记录）：所有 LLM 调用的审计日志。管理员还可以查看已脱敏的输入和应答正文

详情请参阅 [LLM 设置与成本](LLM-zh)。

### Settings（设置，仅限管理员）

**Users**（用户）、**API tokens**（API 令牌：传感器用，仅在创建时显示一次）、**Notifications**（通知渠道：Webhook / Slack / Discord / 电子邮件）、
**System**（系统：版本、环境、数据库、LLM 提供商状态、检测器、后台作业列表及手动执行）。
