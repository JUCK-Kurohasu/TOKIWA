## 設計判断（なぜ）

- **書き込み・実行系ツールは存在しない**。ツールは SELECT のみで、`read_only_session()` は commit せず必ず rollback。
  LLM が作るのは「検証済みパラメータ」だけで SQL 文字列ではない。`path_contains` は `icontains(autoescape=True)`（`%`/`_` はリテラル）。
- **ツール結果は非信頼データ**: 射影時に長い文字列を切り詰め（body 300 字など）、`redact_obj` 後に
  `copilot.max_tool_result_chars`（既定 12000）に収まるまで最大のリストを末尾から削る（`truncated`/`omitted_items` を付与）。
  最後に `untrusted_block()`（`<`/`>` エスケープで封筒を閉じられない）。SSE の `tool_result` は要約のみでデータ本体は流さない。
- **ループ**: `gateway.chat()` を最大 `max_tool_iterations` 回。並列ツール呼び出しは 1 つの user メッセージに全 `tool_result`
  をまとめる（失敗は `is_error: true`）。最後の 1 回の前に「これ以上ツールを呼ばず回答せよ」の注記を tool_result メッセージに
  追記（DB にも保存するので再送が忠実）。最後の呼び出しでなおツール要求が来たら実行せず `is_error` で閉じ、`max_tool_iterations`。
- **履歴は追記のみ（append-only）**: assistant の provider-native ブロック（thinking 含む）を `blocks` にそのまま保存して再送。
  システムプロンプトは会話単位で固定（コンテキスト要約は作成時にスナップショットして `context._snapshot` に保存、API では非表示）。
  現行 Claude は thinking ブロックを生成時の会話に束縛するため、履歴改変・システム差し替えで 400 になりうる（claude-api スキルで確認）。
- **履歴の切り詰め**: `max_history_messages` と入力予算（`llm.max_input_tokens_per_call × 3` 文字）を超えたら、ツール往復の途中では
  切らず analyst 発言の境界から開始し、その場合に限り保持ターンから thinking ブロックを除去（text / tool_use は残す）。
- **中断の修復**: クライアント切断で tool_use に対応する tool_result が無い履歴は、次回に合成 `is_error` tool_result で補う。
- **role**: `user` / `assistant` / `tool`（LLM には user ロールで再送）/ `notice`（UI 専用。LLM 未設定案内・エラー・拒否・上限。再送しない）。
- **LLM 未設定（mock）**: LLM を呼ばず、設定方法（`ANTHROPIC_API_KEY` / openai_compat / LLM 設定画面）を `text` で返す。
- **権限**: 会話は所有者のみ。admin は閲覧・削除可（一覧は `?all=true`）。送信は所有者のみ（admin でも他人の会話には 403）。
  存在しない/他人の会話は区別せず 404。同一会話への同時送信は 409（プロセス内ロック）。
- **ユーザー入力も redact**（長さ上限は外す。スキーマで 8000 字上限）。会話タイトルは初回発言（redact 後）から自動設定。

## 既知の制約・次の一手

1. テキストはトークン逐次ではなく assistant ターン単位で送る（仕様上「一括でも可」）。逐次化は provider のストリーミング対応後。
2. 同時送信ロックはプロセス内のみ。複数ワーカー構成では DB ロック等が必要。
3. `get_asset` の IP 検索と `lookup_vuln` の advisory 紐付けは JSON 列のため Python 側で走査（最大 2000 資産 / 直近 500 件）。
   PostgreSQL 専用化するなら JSONB 演算子に置換可。
4. クライアント切断でループは止まる（途中まで保存、次回修復）。バックグラウンド継続が必要なら `asyncio.shield` + 結果ポーリング。
5. 調整ポイント: `copilot.tier`（コスト/品質）、`max_tool_iterations`、`max_history_messages`、`max_tool_result_chars`、
   各ツールの上限定数（`tools.py` 冒頭）、プロンプト（`prompts.py`、変更時は version を上げる）。
