## 他モジュールへの依頼・注意

- **lab-eval**: `build: {context: .., dockerfile: deploy/Dockerfile}` で利用可。サービスの `command` は
  `["gate", "run", ...]` でも `["tokiwa", "gate", "run", ...]` でも可。HTTP を持たないサービスは
  `TOKIWA_HEALTHCHECK_URL: none`、gate は `http://127.0.0.1:8080/__tokiwa/health` を設定。
- **gate**: `/__tokiwa/health` と、CLI オプション未指定時に `GateSettings`（`TOKIWA_GATE__*` 環境変数）を使うことを前提に
  compose の gate プロファイルを書いた。違う場合は `deploy/compose.yaml` の gate を調整してほしい。
- **sigma**: ルールは `rules/` に置けばイメージの `/app/rules` に入り `TOKIWA_DETECTION__SIGMA_RULE_DIRS=["/app/rules/sigma"]`。
- **統合担当**: mypy は既存 6 エラーのため CI では continue-on-error。直したら外す。HANDOFF.md・architecture.md は未編集
  （deploy/ はすでに architecture.md §3 に記載あり）。
- 全員: `TOKIWA_*` を空文字で設定すると空値として有効になる（例: `TOKIWA_SERVER__SECRET_KEY=` → 空の JWT 鍵）。
  config 側で空文字を None 扱いにするかは要判断（config.py は共有ファイルのため触っていない）。
