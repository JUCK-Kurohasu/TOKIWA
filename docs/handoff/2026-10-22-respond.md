## 他モジュールへの依頼

- **deception**: `deploy_canary` は `tokiwa.deception.service.create_asset(DeceptionAssetIn) -> 何か(.id か ["id"])` と
  `delete_asset(asset_id)`（または `disable_asset`）をダックタイピングで呼ぶ。名前が違う場合は合わせるか連絡を。
  無い間は `deploy_canary` は `failed` になる（仕様どおり）。
- **gate**: `/api/v1/gate/policy` は `ETag` を返し `If-None-Match` で 304。使うかは任意。`blocked`/`deceive` は
  集約済み CIDR、v4→v6 昇順。
- **triage**: `propose_action()` は検証失敗で `None`、重複は既存アクションを返す（例外は投げない）。
- **frontend-ops**: 承認 API は実行結果込みで返る（`active` / `expired`(one-shot) / `failed`）。状態違反 409、
  検証 422（`detail` に理由）、revert 失敗 502。一回限りの notify/webhook は成功時 `expired` + `result.one_shot`。
- **frontend-core(settings)**: 通知チャネル PATCH はマスク値をそのまま返せば秘密を保持。`DELETE` は 204。
  暗黙の既定チャネル（`notify.default_webhook_url`）は一覧に出ないが `POST /notify/channels/default/test` は可。
