## SDK で確認した事実（anthropic 2.1.0 をローカルで inspect）
- `client.beta.messages.parse` は `fallbacks` / `betas` / `output_format` を同時に受け付ける
  → **parse とサーバーサイドフォールバックは併用可**（MockTransport で送信ボディ・ヘッダを確認）。
  非 beta の `client.messages.parse` には `fallbacks` が無い。
- `parse()` は全テキストブロックを `TypeAdapter.validate_json` で検証し、失敗すると `pydantic.ValidationError` を
  送出（usage も失われる）→ `with_raw_response.parse` を使い、失敗時は `BetaMessage.construct(**await raw.json())`
  で usage・stop_reason・本文を回収。非 beta の `messages.with_raw_response` には `parse` が無いので beta 名前空間に統一
  （フォールバック非対象モデルでは beta ヘッダ・fallbacks を送らない＝通常の Messages API 呼び出し）。
- `BetaFallbacksParam = Iterable[BetaFallbackParam] | Literal["default"]`。usage に `iterations`
  （`message` / `fallback_message` / `compaction` / advisor）・`server_tool_use.web_search_requests` がある。
- `stop_details`（`BetaRefusalStopDetails`）: category（cyber/bio/frontier_llm/reasoning_extraction/general_harms/null）、
  explanation、recommended_model、fallback_credit_token。
- `anthropic.transform_schema` が公開されている（strict ツール用のスキーマ変換に使用）。
- respx は `httpx` しかパッチしないので SDK（httpx2）の通信は見えない → Anthropic のテストは
  `AsyncAnthropic(http_client=DefaultAsyncHttpxClient(transport=httpx2.MockTransport(...)))` を注入
  （`AnthropicProvider(settings, client=...)`）。SDK のリクエスト構築・レスポンス解析は本物が動く。
  OpenAI 互換は httpx を使うので respx でテスト。

## 設計判断
- Web 検索 + 構造化出力は 2 回呼び出し（調査 → 抽出）。理由: 構造化出力は citations 非対応（ドキュメント）、
  かつ parse が Web 検索応答の複数テキストブロックを検証できない。抽出時に調査レポートを `untrusted_block` で封入。
- `pause_turn` は公式パターン（元の user + 直近の assistant 内容で置き換えて再送）で最大 4 回。
- フォールバック対象: `claude-opus-5*` / `claude-sonnet-5-5` / `claude-fable-5*` / `claude-mythos-5*`
  （Haiku 5.5 はサーバーサイドフォールバック無し）。`llm.enable_fallbacks=False` で無効化。
- usage: `fallback_message` があれば `iterations` の message + fallback_message を合算（トップレベルは最終試行のみのため）。
- strict ツールは API に拒否されたら 1 回だけ strict なしで再送し、以後そのプロバイダでは使わない。
- 起動時オーバーレイ適用は「保存済みオーバーレイがあるときだけ」gateway を再構築
  （テストで `mock_llm` を先に入れても上書きしない）。
- `GET /llm/config` の `provider` は設定値、`active_provider` は実効値（フォーム往復で auto が mock に化けないように）。
