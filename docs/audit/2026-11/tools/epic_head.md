## 読み方と限界

| 確度 | 意味 |
|---|---|
| `confirmed` | 手元で再現した（コマンドと観測結果を Issue に記載） |
| `likely` | コード上で経路を確認した（未実行） |
| `hypothesis` | 推測。検証が必要 |

- **実 LLM は一度も呼んでいません**（すべて mock）。LLM の応答内容に依存する指摘は `likely` / `hypothesis` 止まりで、`needs-live-llm` ラベルが付いているものは実モデルでの確認が必要です。
- **実物の ARTEX は走らせていません**。ARTEX についての指摘はソース読解に基づきます（file:line を記載）。
- 攻撃トラフィックは localhost のラボにしか送っていません。性能の数値はサンドボックス（4 コア共有）での実測で、絶対値より傾向を見てください。
- 重大度は監査側の判断です。水増しはしない方針ですが、運用環境（PostgreSQL か、Gate の前段にプロキシがあるか、自動承認を使うか）で上下します。
