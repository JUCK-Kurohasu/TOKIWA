## 読み方と限界

| 確度 | 意味 |
|---|---|
| `confirmed` | 手元で再現した（コマンドと観測結果を Issue に記載） |
| `likely` | コード上で経路を確認した（未実行） |
| `hypothesis` | 推測。検証が必要 |

- **実 LLM は一度も呼んでいません**（すべて mock）。LLM の応答内容に依存する指摘は `likely` / `hypothesis` 止まりで、`needs-live-llm` ラベル（一覧では ⚠️）が付いているものは実モデルでの確認が必要です。
- **実物の ARTEX や他の AI 攻撃ツールは走らせていません**。ARTEX についての指摘はソース読解（file:line を記載）、他のツールは公開資料に基づきます。「ARES」は同名の公開ツールが複数あり、どれを指すか特定できていません（#116 と `docs/audit/2026-11/repro/L02/pass2/NOTES.md`）。
- 攻撃トラフィックは localhost のラボにしか送っていません。性能の数値はサンドボックス（4 コア共有）での実測で、絶対値より傾向を見てください。
- 個人データに関する指摘（#156 ほか）は「何が保存・送信されるか」という事実のみです。法令の一次資料はこの監査環境から開けなかったため、法的な論点はすべて未確認で、結論は書いていません。
- 重大度は監査側の判断です。水増しはしない方針ですが、運用環境（PostgreSQL か、Gate の前段にプロキシがあるか、自動承認を使うか）で上下します。
